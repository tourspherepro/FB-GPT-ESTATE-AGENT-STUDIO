# **App Name**: EA Tools

## Core Features:

- User Authentication: Secure user sign-up and login functionality with authentication to allow access to the platform's tools.
- Dashboard: A central dashboard to display available tools to the user, per the user's permission level.
- Floor Plan Maestro: Tool to automatically generate a marketing ready floor plan from a hand drawn floor plan.
- Prop Pro Images: Generative AI tool that enhances property photos with staging, repairs, or seasonal decorations, using a specific user-uploaded image as a tool for knowing the properties structure and architecture.
- 360 Tour Sphere: Tool that allows creation of 360° virtual tours from uploaded panoramic images.
- EA Analyze: Tool that utilizes a local LLM that when give data, will create the requested data in real time.
- EA Description: Generative AI tool to create compelling property descriptions based on property features. An AI tool is incorporated into this feature to refine the AI output and make corrections or edits when required.
- Admin Settings: Admin-only section for user management and permission settings to determine tool access.
- Footer Notice: Static copyright notice (c) estateagent.tools 2025 at the bottom center of the page.

## Style Guidelines:

- Primary color: Rich blue (#4285F4), evoking trust and professionalism, important for real estate.
- Background color: Light grayish-blue (#E8F0FE), for a clean, modern, trustworthy feel.
- Accent color: Vivid orange (#FF5722) to draw attention to key interactive elements.
- Body and headline font: 'Inter', a sans-serif font for a modern, objective look that's very readable.
- Use clean, minimalist icons to represent each tool on the dashboard.
- Dashboard-style layout with clear sections for each tool, prioritizing ease of access.
- Subtle transitions and animations on user interactions to provide feedback and a modern feel.
